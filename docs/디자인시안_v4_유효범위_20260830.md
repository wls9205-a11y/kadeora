# 디자인시안 V4 「네이비 인덱스」 — 유효 범위 요약 (2026-08-30)

> `docs/디자인시안_v4_네이비인덱스.html`을 읽는 사람을 위한 문서. 시안은 **시각 언어의 정본**이지 화면 스펙이 아니다. 실구현과 갈린 지점은 아래 무효 목록이 정본이며, 근거는 판정 증분1~12에 있다.

## 해석 계층 (상위가 이긴다)

1. Node 직접 지시
2. 지시서 DS3-V4 + 판정 증분 1~12 (표준 변경을 명시한 경우 저장소 표준도 바꾼다)
3. 저장소 기확정 표준 (H5 「선택=네이비」, DS_RULES, lead-copy 등)
4. 시안 — **시각 언어에 한해** (색·라운드·타이포·마스트/섹션/리스트 문법)
5. 시안의 숫자·목록 내용·데이터 예시 — **무효** (예시일 뿐 스펙이 아니다)

## 유효 — 시안이 정본인 것

단색 네이비 마스트헤드·서브마스트 + 하단 골드 2px · 골드 룰 22×2 + eyebrow(기존 모노 스펙) 섹션 머리 · 풀블리드 헤어라인 리스트(kd-lrow 골격, tabular 우측 숫자, 열 캡션) · 언더라인=뷰 전환 / 칩=필터 의미론 · 이동은 목록 바닥 문장형(SectionLink) · 그라디언트는 썸네일·히어로 카드·등록 버튼에만 · 골드 텍스트는 네이비 위에서만(흰 바탕은 도형 룰만, 장식 규정) · 상세 네이비 히어로 블록 + 폼(네이비 헤더·그레이 필 인풋) + 하단 CTA 48.

## 무효 — 실구현이 정본인 것

**전 화면**
- 섹션 머리 우측 텍스트링크 → 없음, 바닥 문장형 (증분1 ④)
- 행 42px → 인터랙티브 행 --touch-min(44+) 하한, 정보 행만 40 (증분1 ③·증분2)
- 활성 「틴트」 → 네이비 **단색** — H5 기확정 (증분7)
- 시안의 모든 수치·현장명·가격·글 제목 = 예시 (증분3)

**/stock** — 지수 3분할(코스피 레벨 등)은 DB에 없는 값이라 미구현 · 언더라인은 시장 축 1줄만(정렬·테마는 칩) · 열 캡션은 순위/종목/현재가 · 서브마스트 타이틀은 h1이 아님(sr-only h1 보존) (증분3)

**/blog** — 조회수·HOT 표기 없음(합성값) · 카테고리 탭=색인 URL 뷰라 언더라인(kd-utab), 서브카테고리=파셋 칩 — 시안의 단층 칩 줄과 다름 (증분6·11)

**/apt** — 지역 트리거는 우측 슬롯 칩이 아니라 전폭 버튼(선택 상태 요약 계약) · 단계 필터는 칩 6개가 아니라 「숫자·라벨」 스트립 · 큐레이션은 36px 행이 아니라 카드 캐러셀(D-day·진행 레일·CTA — 카드가 허용된 유일한 자리) · **리드 스트립 폐기**(Node 지시 — 단, 상세 LeadForm·하단 CTA·기축 상담 폼은 유효) (증분8·9)

**홈** — 칼럼·증시 섹션 자체가 없음(8/25 홈 제거 기지시 유지, 증분12 (가)) · 리드폼 없음(기지시) · 이미지 승격은 피처드 1개만 · **히어로는 그라디언트를 유지한다** — `--brand-hero-bg` 는 `src/lib/og/brand.ts` 의 `BRAND_BG` 와 바이트 단위로 묶여 있어 단색으로 바꾸면 OG 카드와 첫 화면이 갈린다. 마스트헤드 단색 규칙은 `kd-masthead` 로 여전히 유효하고, 홈 히어로가 예외다 (V4-5)

## 한 줄 요약

시안에서 가져갈 것은 **옷**(네이비·골드·리스트·섹션 문법)이고, **몸**(무슨 정보를 어떤 구조로 내는가)은 언제나 실구현·기지시가 정한다.

## 부록 — 갈림 7건이 한 성격이었다 (CC 실측, F-5)

이 문서의 「무효」 항목은 흩어진 예외가 아니다. 7건 중 6건이 **시안이 화면을 단순화하면서 실물이 지고 있던 정보나 결속을 안 그린** 결과다.

| 화면 | 시안이 안 그린 것 |
|---|---|
| /stock | 지수 «레벨» 데이터가 애초에 없다는 사실 |
| /stock | 시장 × 정렬 2축이 곱해지는 구조(v7-C1) |
| /blog | 순위 열 — 그래서 캡션이 3열이 아니라 2열로 보였다 |
| /apt | 지역 트리거가 «선택 상태를 문장으로 말하는» 계약 |
| /apt | 단계별 «건수» 가 앞서는 구성 |
| /apt | 큐레이션 카드의 D-day·7칸 진행 레일·확인 날짜·알림 CTA |
| 홈 | 히어로 배경이 OG 카드와 «바이트 단위로» 묶여 있다는 것 |

⚠️ 그래서 시안을 볼 때의 질문은 「이게 예쁜가」가 아니라 **「이 자리에서 실물이 무엇을 지고 있었나」** 다.
   시안이 비운 자리는 «비워도 되는 자리» 가 아니라 «시안이 몰랐던 자리» 일 수 있다.
