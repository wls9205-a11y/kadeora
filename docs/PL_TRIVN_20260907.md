## low-cs 등록 — 이 등록의 성격

**`content_score` = 0 인 상태로 등록했다.** cs 는 색인(noindex) 기준일 뿐 광고 착지와 무관하고,
착지는 걸쇠 ④가 실물로 봤다. 인리치 48h SLA 안에 cs 가 오르는지는 **세션 A 예약 관측**이다.

`pl_add_site_keywords.py` 에 `--allow-low-cs` 를 냈다. `sa.SQL` 의 `content_score >= 40` 은
「전국 일괄 생성에서 무엇을 만들지」를 고르는 **스코프 필터**이지 광고 적격이 아닌데, 갓 시드된 현장은
정의상 cs 0 이라 긴급 등록 도구가 정작 대상인 **신규 대어에만 구조적으로 닫혀** 있었다
(일광·그랑라크가 안 걸린 건 이미 cs≥40 이었기 때문이다). 조건 4항 그대로 집행했다:

- `sa.py` **불가침** — 문턱을 낮추면 전국 생성이 통째로 달라진다. 수정은 러너 한 파일뿐.
- 문턱만 비켜 가고 적격은 **더 좁게** 본다 — `unscoped_site()` 가 DB 단건 조회로
  `is_active=true` · `ad_blocked=false` · `supply_type=민영` · 단계 광고적격 **4/4** 를 확인하고
  하나라도 어긋나면 등록하지 않는다(아무것도 확인하지 않는 `--name` 보다 강한 문).
- 단계 집합은 **다시 적지 않고** `src/lib/apt/lead-eligibility.ts` 의 `LEAD_ELIGIBLE_STAGES`(14단계)를
  파싱해 쓴다 — 착지 프로브가 보는 판정과 등록이 보는 판정이 갈리면 폼 없는 페이지에 광고를 붙이게 된다.
- 비켜 가는 것은 자동이 아니라 **플래그**다(`--ignore-lockout` 과 같은 규율).
