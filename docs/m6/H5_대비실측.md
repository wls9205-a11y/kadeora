# H5-D1 대비 실측 — 2026-08-27

측정 방식: WCAG 2.x 상대휘도. **투명도는 전부 합성한 뒤 잰다**(Rule #85).
하한 4.5:1 (Rule #86). 재현: `docs/m6/H5_대비실측.md` 하단 스크립트.

---

## 1. 지시서가 요구한 4쌍 — 전부 통과

| 조합 | 대비 | |
|---|---|---|
| 흰 `#FFFFFF` / 네이비 `#0B2A6B` | **13.48:1** | OK |
| 골드 `#FFC53D` / 네이비 `#0B2A6B` | **8.54:1** | OK |
| 흰 `#FFFFFF` / 네이비-mid `#123A8F` | **10.36:1** | OK |
| 네이비 `#0B2A6B` / 흰 | **13.48:1** | OK |

---

## 2. ⚠️ 4쌍만 재면 놓치는 것 — 히어로는 «단색이 아니라 그라디언트» 다

`--brand-hero-bg` 는 `158deg, #0B2A6B 0% → #123A8F 52% → #2563EB 100%` 다.
4쌍은 앞의 두 정지점만 본다. **끝점 `#2563EB` 를 재면 두 개가 떨어진다.**

| 배경 지점 | 흰 글씨 | 골드 글씨 | 흰 칩(0.14) 위 흰 글씨 |
|---|---|---|---|
| `#0B2A6B` (0%) | 13.48 | 8.54 | 8.94 |
| `#123A8F` (52%) | 10.36 | 6.56 | 7.06 |
| **`#2563EB` (100%)** | 5.17 | **3.27 ✗** | **4.03 ✗** |

좌상단 광원(`BRAND_GLOW`, 흰 0.20)까지 합성하면 어두운 쪽도 내려간다.

| 광원 합성 후 | 흰 | 골드 |
|---|---|---|
| `#0B2A6B` + 0.20 | 7.36 | **4.66** (여유 0.16) |
| `#123A8F` + 0.20 | 6.04 | **3.83 ✗** |

⚠️ 광원은 좌상단(12% 6%)이고 밝은 끝은 우하단이라 **최악값 둘이 같은 지점에서 겹치지는
않는다.** 그래도 골드는 두 방향 모두에서 여유가 거의 없다.

### 그래서 H5-1 에 넘기는 제약 (이번 커밋에서 고치지 않음)

1. **골드 줄은 히어로 «위쪽»에만.** 카피 3줄이 상단에 있으면 배경은 `#0B2A6B~#123A8F`
   구간이라 6.5 이상이 나온다. 아래로 내려가면 안 된다.
2. **검색창 아래 칩은 스크림 위에 얹는다.** 칩은 히어로 하단이라 `#2563EB` 쪽이다.
   `rgba(255,255,255,0.14)` 그대로 두려면 하단에 네이비 스크림이 필요하다.
3. ⛔ **그라디언트 값을 고쳐서 해결하지 않는다.** `brand.ts BRAND_BG` 와 바이트가
   같아야 하고, OG 카드는 satori 가 그려서 CSS 를 안 탄다 — 한쪽만 바뀐다.

---

## 3. 골드를 흰 배경에 쓰면

| 조합 | 대비 |
|---|---|
| 골드 `#FFC53D` / 흰 | **1.58:1** ⛔ 글자가 사실상 안 보인다 |
| `--accent-yellow` `#854D0E` / 흰 | 6.85:1 |

**흰 배경에서 노랑이 필요하면 `--accent-yellow`.** 골드는 네이비 위 전용.

---

## 4. `--accent-amber` 3종 — 정의가 없어 «폴백이 화면을 칠하고 있었다»

`var(--accent-amber, #f59e0b)` 계열이 **5줄 7곳**에서 폴백으로 렌더되고 있었다
(지시서 추정 2곳보다 많다). `#f59e0b` 는 흰 배경 대비 **2.15:1** — 하한 미달이다.

| | 대비 |
|---|---|
| 기존 폴백 `#f59e0b` / 흰 | **2.15:1 ✗** |
| 신규 `--accent-amber` `#854D0E` / 흰 | **6.85:1 OK** |
| `--accent-amber-bg` 합성면 `#FAF3E6` 위 `#854D0E` | **6.21:1 OK** |

값을 새로 고르지 않고 형제 토큰 `--accent-yellow` 와 **같은 값**으로 맞췄다.
새 색을 만든 게 아니라 이미 검증된 값에 이름을 붙인 것이다.

⚠️ 이건 **화면 색이 실제로 바뀌는 변경**이다(주황 → 진한 갈색). D1 의 다른 항목은
화면 변화가 0 이지만 이 7곳은 아니다. 의도한 것이고, 근거는 위 2.15:1 이다.

### 남은 별건 (이번에 안 고침)

`globals.css` 의 amber 수치 표시 1곳이 `font-weight: 800` 이다. TY1 사다리는 800+ 를
쓰지 않는다(satori 예외). 인라인이 아니라 CSS 라 TY1 스윕에 안 걸렸다.
