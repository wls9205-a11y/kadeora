# P1 원인 조사 + §3-1 표본 관문 결과 — 2026-08-26

**결론 두 줄**

1. **파서는 고장나 있지 않다.** 지금 돌리면 정상 작동한다(32,059자 추출, 200자 문턱 통과).
2. **`pdf_parse_version = -1` 2,483건이 게이트를 막아 파서가 «아예 실행되지 않고» 있었다.**
   그리고 **`-1` 을 쓰는 코드가 저장소에 없다.**

## 1. `-1` 의 출처 — 코드가 아니다

```
$ grep -rn "pdf_parse_version" src --include=*.ts
apt-parse-pdf-pricing/route.ts:387   ud.pdf_parse_version = 1;     ← 성공만 쓴다
apt-parse-announcement/route.ts:97   ud.pdf_parse_version = 0;     ← 미파싱 표시
apt-summary-gen/route.ts:80          .gte("pdf_parse_version", 1)  ← 소비자
```

**`-1` 을 대입하는 코드가 한 줄도 없다.** 2,483건은 수동 SQL·채팅 계열의 1회성 작업으로
찍힌 값이다. 2026-08-24 `redevelopment_projects` 1,105행 재생성 사건과 **같은 계열** —
재발 조건이 코드 밖에 있다.

### 왜 치명적인가

하위 크론의 게이트가 이것이다.

```ts
.or('pdf_parse_version.is.null,pdf_parse_version.eq.0')
```

`-1` 은 `null` 도 `0` 도 아니다. → **영구 스킵.** 파서를 아무리 고쳐도 2,483건은
자동으로 다시 시도되지 않는다. 그리고 크론은 「대상 0건」을 찍고 **정상 종료** 한다 —
「할 일이 없다」와 「전부 스킵됐다」가 로그에서 구분되지 않는다.
이 저장소가 `if (!error)` 46곳으로 넉 달을 잃은 것과 같은 침묵이다.

### ⚠️ 함정 #10 이 5건 중 4건에서 실증됐다

**사업지 주소와 견본주택 주소가 전부 다르다.**

```
두산위브 대연   사업지 남구 대연동 1756-9   ↔ 견본주택 남구 문현동 1251
더샵 트리센트   사업지 남구 문현동 334      ↔ 견본주택 수영구 수영동 517
장안지구 B-2    사업지 기장군 장안읍 좌동리 ↔ 견본주택 기장군 정관읍 달산리
에코델타 리버시티 사업지 강서구 강동동      ↔ 견본주택 사하구 당리동
```

**구(區)가 다르다.** 혼동하면 지도가 틀린다. 라벨을 명시해 추출해야 한다.

### 실패한 1건의 양상

알티에로 광안은 `견본주택 (주소 : …)` · `견본주택 소재지 …` 두 패턴 어디에도 안 맞았다.
텍스트는 123,534자로 정상 추출됐으므로 **양식 변형** 이지 스캔본이 아니다.
정규식만으로는 이 변형을 다 못 잡는다 — **§3-2 의 ANTHROPIC 문서 입력 추출이 필요한
근거가 바로 이것** 이다(「문서에 없으면 null」 강제와 함께).

한편 4건이 같은 패턴(`견본주택 (주소 : …)`)으로 잡히므로 **정규식을 1차, LLM 을 2차 폴백**
으로 두면 비용을 크게 줄일 수 있다.

## 4. P1-v2 에 반영할 것

1. **`-1` 을 「영구 스킵」이 아니라 「버전 미달」로 다룬다.**
   게이트를 `pdf_parse_version.is.null,eq.0` 이 아니라
   **`pdf_parse_version < PARSER_VERSION`** 비교로 바꾼다. 그러면 파서를 고칠 때마다
   상수 하나만 올리면 전량이 자연스럽게 재처리된다. 일괄 리셋이 필요 없어진다.
2. **모델하우스 필드 추출을 «추가» 한다.** 성공한 145건조차 `model_house_*` 가 0인 것은
   파서가 그 필드를 애초에 안 뽑기 때문이다. 파싱 실패와 무관한 별개 결손이다.
3. **사업지/견본주택 라벨을 분리해 추출한다** (함정 #10 — 5건 중 4건이 구가 다르다).
4. **정규식 1차 → LLM 2차** 로 두어 비용을 줄인다. 4/5 는 정규식으로 잡힌다.
5. **「대상 0건」을 성공으로 보고하지 않는다.** 스킵 사유별 건수를 응답에 넣는다 —
   `-1` 로 막힌 건수가 로그에 보였다면 이 조사가 필요 없었다.
