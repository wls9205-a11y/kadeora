- 같은 계정 `A_분양` 에 같은 키워드가 **500원 · 일광 상세 착지**로 살아 있다(1,925imp/9clk).

⚠️ 이 키워드는 계정 전체로 보면 **4중**이다 — `일광더에스`(450) · `일광 더에스 큐샵`(440)

경쟁은 남는다. 「이중 해소」로 기대치를 잡지 않는다.

| 경로 | 명령 | 산출 |
|---|---|---|
| **OFF** ← 세션 A 권고 | `python tools/naver-sa/sa.py off --csv docs/pl/PL_C1_A_일광더에스_OFF_20260906.csv --live` | userLock=true · 재조회 검증 |
| **URL 부여** | `python tools/naver-sa/pl_c1a_landing_set.py --live` | 착지 = A_분양과 «같은» 일광 상세 |

> 세션 A: 「URL 을 부여해도 A_분양 500원 상세착지와의 3중만 남고, 140원짜리가 노출을

- URL 경로 스크립트는 목적지 200 을 **먼저** 확인하고(9/5 실측 200), `fields=links` 로
  부분 갱신하며, 실행 후 재조회로 **착지 반영 + 입찰가 불변**을 둘 다 센다.
- ⛔ Node 의 한 단어(`OFF` 또는 `URL`) 없이 어느 쪽도 실행하지 않는다.

### 그랑라크 2건 — 세션 A 권고로 **원안 뒤집기**

⚠️ 남는 E_대표 쪽은 **허브 착지 · 70원**이라 리드폼이 없고, 꺼지는 A_분양 쪽이
