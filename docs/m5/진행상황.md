       `catColorMap`(blog 브레드크럼)은 배경 없이 쓰지만 다섯 값 모두 진한 토큰이다.
       **위험한 것은 쌍 중 하나라도 `#FFFFFF` 인 경우다** — `stockChipStyle` 이 유일했다.
       새 `{bg, fg}` 쌍을 만들 때 fg 에 흰색을 넣는다면 그 쌍은 «반드시» 붙여 쓸 것.

13. **토큰 자체 손보기 — 별도 판단 (그때그때 하지 말 것)**
    `--accent-blue`·`--accent-purple` 두 형제만 제 `*-bg` 틴트 위에서 5:1 아래다.
    실측(글자색 / 흰 배경 / 제 틴트 위):
    ```
      --accent-red    #991B1B  8.31  7.12
      --accent-green  #065F46  7.68  6.81
      --accent-orange #9A3412  7.31  6.47
      --accent-cyan   #155E75  7.27    —
      --accent-yellow #854D0E  6.85  6.22
      --accent-purple #7C3AED  5.70  4.91   ← 형제 중 낮다
      --accent-blue   #2563EB  5.17  4.50   ← 가장 낮다. 하한에 0.00 여유
    ```
    **둘 다 4.5 는 «넘는다»** — 지금 당장의 결함은 아니다. 다만 `--accent-blue` 는
    여유가 0 이라, 그 위에 알파가 하나만 더 얹히면 즉시 미달이 된다.
    실제로 TY1-2 의 「분양중」 배지가 그렇게 4.49 로 떨어졌고 그때는 «사용처» 를
    `--brand-dark` 로 바꿔 해결했다 — 토큰은 건드리지 않았다.
    ⚠️ 사용처를 기존 토큰으로 바꾸는 것은 계속 그때그때 한다.
       **토큰 값 자체를 바꾸는 것은 파급이 전 화면이라 별도 판단이다.**
14. TossTeaser 그라데이션 두 곳 — `linear-gradient(#1B64DA → #3182F6)` 위 흰 글씨.
    밝은 쪽 끝(#3182F6)에서 3.71 이다. 솔리드 버튼(TossBottomBanner)은 팔레트 안의
    `#1B64DA` 로 고쳤으나, 그라데이션은 중간값을 새로 정해야 해서 두었다.
    파트너 브랜드 면이라 색 선택에 판단이 필요하다.

## 환경 메모

- Python 은 `%LOCALAPPDATA%\Programs\Python\Python312\python.exe` (PATH 미등록)
- 자격증명은 **User 환경변수**에 있고 셸 세션엔 없다. 실행 전 주입해야 한다.
- Supabase 풀러가 «간헐적으로» 인증 실패를 낸다. 지문이 같으면 자격증명 문제가 아니라
  일시 오류다 — 재시도할 것. `sa.py` 실행에 3회 재시도를 넣어 뒀다.
- `out/` 에는 부울경 완성본이 들어 있다. 다른 zone 을 build 하면 «덮어쓴다» —
  `out_부울경/` 에 사본이 있다.
