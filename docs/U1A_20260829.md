## 부록 — 실행 중 발견 (U-1a)

### A-1. 확신도 어휘가 «설계와 구현에서 갈려 있다» (2026-08-29)

| 출처 | 값 |
|---|---|
| 설계 `PV_INSTRUCTION §D6` | `verified`(독립 출처 2개 일치) · `estimated`(단일 출처) · **`conflicting`**(출처 충돌) · `rumor` |
| 구현 (`apt_permits` DB 제약 · 코드 리터럴) | `verified` · `estimated` · **`confirmed`** · `rumor` |

`confirmed` 는 D6 에 **없고**, `conflicting` 은 구현에 **0건**이다.

⛔ DS-2a 에서 CC 세션 B가 「`conflicting` 은 검수 큐 이름이지 확신도가 아니다」로 **단정했고 그것은 틀렸다** —
마스터의 「conflicting 큐」만 보고 D6 를 확인하지 않은 결과다.

→ **화면은 둘 다 렌더한다.** 어느 쪽도 「미확인」으로 떨어뜨리지 않는다.
→ **어휘 통일은 PV 트랙 판단**이다(제약에 `conflicting` 추가 / D6 에 `confirmed` 추가 중 택1).
   화면의 몫은 «오는 값을 정직하게 표시» 하는 것까지다.
